# Lab Work Log

## Purpose

This folder contains timestamped lab work session logs for the DTCP project. Each markdown file documents a specific lab session, including:

- **Date**: Session date
- **Attendees**: Team members present
- **Hours**: Duration of the session
- **Results**: Work completed across different subsystems (Firmware, Hardware, etc.)

## Usage

Add a new markdown file for each lab session with the naming convention `M_DD_YYYY.md` (where M is month without leading zero). Include session details, attendees, hours worked, and results.
